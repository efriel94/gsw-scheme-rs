# GSW Scheme in Rust

This repository is an implementation of the GSW (Gentry-Sahai-Waters) scheme in Rust for educational purposes.

The GSW scheme is SHE (Somewhat Homomorphic Encryption) scheme that supports additive and multiplicative HE operations.
